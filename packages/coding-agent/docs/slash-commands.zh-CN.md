# 斜杠命令

在 Pi 的终端编辑器中输入 `/`，搜索当前会话可用的命令。本页列出当前 Pi 版本中的内置命令。

扩展、提示词模板和技能可以添加命令。因此 Pi 中的命令菜单才是你会话所加载资源的准确参考。

## 模型与设置

| 命令 | 说明 |
|---|---|
| `/settings` | 打开设置 |
| `/model [provider/model]` | 选择模型 |
| `/thinking [level]` | 设置思考级别 |
| `/scoped-models` | 配置交互式循环切换使用的模型 |
| `/login [provider]` | 添加提供商认证 |
| `/logout` | 移除提供商认证 |
| `/llama` | 管理所配置 llama.cpp 路由上的模型 |

## 会话与上下文

| 命令 | 说明 |
|---|---|
| `/new` | 开始新会话 |
| `/resume` | 切换到另一个已保存的会话 |
| `/name [name]` | 设置会话显示名称；省略时显示当前名称 |
| `/session` | 显示当前会话信息与统计 |
| `/tree` | 浏览会话树 |
| `/fork` | 从较早的用户消息创建新会话 |
| `/clone` | 在当前位置复制当前会话 |
| `/compact [instructions]` | 压缩当前上下文，可带自定义指令 |
| `/import <path>` | 导入并恢复一个 JSONL 会话 |

## 导出与分享

| 命令 | 说明 |
|---|---|
| `/copy` | 复制最后一条助手消息 |
| `/export [path]` | 把会话导出为 HTML 或 JSONL |
| `/share` | 上传会话并返回查看链接 |
| `/bug [description]` | 为 Pi 开发者准备私密 bug 报告 |

导出或分享之前先审查会话。会话可能包含 prompt、工具参数、命令输出、文件内容以及对话中暴露的凭据。

## 运行时与项目

| 命令 | 说明 |
|---|---|
| `/trust` | 保存项目信任决定，供以后的 Pi 进程使用 |
| `/reload` | 重新加载按键绑定、扩展、技能、模板、主题和上下文文件 |
| `/hotkeys` | 显示生效的键盘快捷键 |
| `/changelog` | 显示 changelog 条目 |
| `/quit` | 退出 Pi |

## 由资源添加的命令

- 扩展可以注册带自己的参数和补全行为的命令。
- 每个提示词模板以其模板名作为命令可用。
- 启用技能命令时，技能以 `/skill:name` 形式可用。

添加或修改了可发现的命令资源后，运行 `/reload`。它们的加载和命名规则见[扩展](extensions.zh-CN.md)、[提示词模板](prompt-templates.zh-CN.md)和[技能](skills.zh-CN.md)。
