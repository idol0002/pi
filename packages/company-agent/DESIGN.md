# 知序：本地知识库网页规范

网页使用 React 19、TypeScript 和现有 CSS。Node 服务启动时通过 esbuild 将 React 和 TSX 组件打包为同源 `/assets/app.js`，不依赖 CDN 或独立前端服务器。修改 `web/` 源码后重启服务并刷新页面。

页面职责：登录表单负责建立会话；侧栏负责知识库选择和历史会话；问答区负责输入、生成状态和引用；知识管理区负责文档及授权；原文弹窗负责鉴权后预览。

使用函数组件与 Hooks，状态由 React 驱动。`app.tsx` 管理登录与工作空间，`use-chat.ts` 管理流式问答，`management.tsx` 管理文档和授权。对话框、滚动和 PDF 画布通过 ref 操作；网络请求与轮询在组件退出或切换时清理，旧请求不能覆盖新视图。

色彩由 `web/styles.css` 的 `:root` 统一定义，其他规则只引用变量：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--background` | `#f5f6f3` | 侧栏、页面底色 |
| `--surface` | `#ffffff` | 输入、卡片、弹窗 |
| `--soft` | `#edf2ee` | 选中态、轻量底色 |
| `--text` | `#20332b` | 正文 |
| `--muted` | `#65756c` | 辅助信息 |
| `--accent` | `#24684c` | 主按钮、链接 |
| `--accent-hover` | `#1b513b` | 主按钮悬停 |
| `--border` | `#dce4dd` | 边框 |
| `--warning` | `#805719` | 演示标识 |
| `--warning-bg` | `#faf2df` | 演示标识底色 |
| `--danger` | `#b13b38` | 错误、删除 |
| `--danger-bg` | `#fff0ed` | 错误提示底色 |
| `--shadow` | `#20332b14` | 阴影、遮罩 |

字体采用系统无衬线字体，代码和原文采用等宽字体。间距以 4px 为单位，圆角采用 8、12、20px。主内容宽度不超过 1120px，问答区不超过 800px。窄屏侧栏通过按钮展开，文档表格可横向滚动。

所有表单使用真实标签，交互元素使用按钮或链接，提供键盘焦点、空态、加载态和错误态。模型和文档内容通过 React 文本节点显示，不解析为 HTML。引用只使用服务器返回的同源文档地址。演示模式持续可见。
