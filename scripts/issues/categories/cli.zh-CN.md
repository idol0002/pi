# cli

编码 agent 的应用外壳、安装和分发。

包含：
- CLI 参数与启动。
- settings.json 的加载、合并、保存，项目与全局作用域。
- pi install、update、remove；npm、pnpm 和 git 包处理。
- 自更新与安装方式检测。
- 独立二进制、nix、npm shrinkwrap、依赖漏洞。
- 崩溃处理与进程退出、整体内存使用和启动时间。

示例：#6600, #7756, #10202, #10519, #10288, #10168, #9972, #10272, #7772。

通常不值得提交：pi.dev 包目录列表问题（不属于本仓库）。
