# tui

终端上的一切：显示与输入。

包含：
- 常规与全屏模式下的 pi-tui 渲染。
- 回滚缓冲、闪烁、重绘开销、流式输出时的 CPU 占用。
- Markdown、语法高亮、图片。
- 消息与工具渲染器、主题、页脚、页眉。
- 提示词编辑器、按键绑定、按键解码（kitty 协议、旧式序列）。
- 粘贴、剪贴板、输入法（IME）、自动补全、外部编辑器。
- 终端回复泄漏到输入、鼠标与选择。

示例：#9255, #8822, #10154, #8212, #9583, #10319, #7321, #10352, #10362, #9497.

通常不值得提交：缺少操作系统、终端或视频的终端专属报告；主题与页脚的调节项（应作为扩展实现）。
